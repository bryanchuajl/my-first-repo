# CLAUDE.md

## Tech Stack
- Plain HTML, CSS, and JavaScript only.
- No frameworks, no build step: files open directly in a browser.

## Project Structure
Nearly empty for now. Currently:
- `README.md` — repository readme
- `CLAUDE.md` — this file

Pages (`*.html`), styles (`*.css`), and scripts (`*.js`) will live at the top level until the project grows enough to need folders.

## Key Requirements
1. Every page must be responsive and work on desktop, tablet, and phone.
2. Users can toggle between a light and a dark theme. The default is the light theme.
3. Text must stay easy to read, with good contrast, in both the light and the dark theme.
